# Publishing to GitHub

Suggested repository name: `interpretable-llm-steering`

Suggested description: Summer REU research on steering Gemma with an actor–critic controller over sparse autoencoder features, including LegalBench experiments and technical presentations.

Suggested topics: `reinforcement-learning`, `mechanistic-interpretability`, `sparse-autoencoders`, `pytorch`, `gemma`, `legalbench`, `undergraduate-research`.

The repository is initialized locally. To publish, create an empty repository on GitHub, then run these commands from this folder, replacing the URL with the repository you created:

```bash
git remote add origin https://github.com/YOUR-USERNAME/interpretable-llm-steering.git
git push -u origin main
```

After publishing, pin the repository on your profile. Use its overview as the project link on your resume. The README is designed to be the first page a reviewer sees.
